# GốmLàng - Website bán hàng tĩnh

Không cần build. Triển khai Vercel: kéo thả thư mục lên vercel.com/new hoặc `vercel --prod`.

- Mật khẩu quản trị mặc định: `admin123` (sửa biến PASS trong js/app.js)
- Dữ liệu lưu trong localStorage của trình duyệt (bản demo).
- Thay `ten-mien-cua-ban.vercel.app` trong các file .html, sitemap.xml, robots.txt bằng tên miền thật.
